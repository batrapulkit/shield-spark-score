# Shield Score

Cybersecurity Assessment for SMBs. This project provides a quick assessment of business cyber risk based on website, email security, and cybersecurity practices.


## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
